# Magic keywords в OMP

Ключевые слова меняют режим работы агента **для одного сообщения**. Пиши их отдельным словом в обычном тексте — не в коде и не в имени файла.

> Работают только в нижнем регистре: `ultrathink`, `orchestrate`, `workflowz`.
> Не сработают варианты вроде `Ultrathink`, `ultrathinking`, `workflowz.ts` или `` `orchestrate` ``.

## Быстрый выбор

| Если нужно… | Пиши | Смысл |
| --- | --- | --- |
| Тщательно разобраться в одной сложной проблеме | `ultrathink` | Максимум размышлений, без обязательного распараллеливания |
| Разделить большую задачу на независимые куски | `orchestrate` | Агент координирует исследование, изменения и проверку |
| Строго провести многофазную работу с параллельными subagent'ами | `workflowz` | Формальный workflow: scope → fan-out → проверки → исправления |

---

## `ultrathink` — «подумай глубже»

Используй, когда главная сложность — **принять верное решение**, а не сделать много независимых действий. Для reasoning-моделей слово запрашивает максимальный доступный thinking effort.

### Хорошие кейсы

- Странный баг зависит от порядка событий или состояния.
- Нужно найти первопричину, а не замаскировать симптом.
- Нужно выбрать между архитектурными вариантами.
- Нужно безопасно спланировать миграцию данных, протокола или API.

### Пример

```text
ultrathink: почему Yazi внутри tmux выбирает Chafa, хотя вне tmux работает
Kitty graphics? Проследи всю цепочку detection и найди первопричину; не
предлагай workaround до проверки.
```

### Не нужен

Для механической работы: переименовать поле, исправить одну настройку, найти файл, добавить один пункт конфигурации.

---

## `orchestrate` — «организуй работу»

Используй, когда задача состоит из **нескольких независимых частей**. Агент сначала определяет поверхность работы, затем делит её между subagent'ами, проверяет результат и собирает итог.

### Хорошие кейсы

- Обновить зависимость, адаптировать локальные патчи и проверить регрессии.
- Изменить feature, затрагивающую frontend, API и storage.
- Исследовать несколько подсистем и не пропустить callsites.
- Провести большой, но понятный рефакторинг.

### Пример

```text
orchestrate: обнови OMP до последней версии. Проверь drift monkey-patches,
пересобери bundle, сделай smoke и PTY visual verification. Не коммить.
```

### Не нужен

Для одной маленькой правки. Оркестрация тогда дороже самой работы.

---

## `workflowz` — «проведи работу по строгому workflow»

Используй для большой задачи, где важно не только сделать изменения, но и **доказать полноту покрытия**. Это строгая версия orchestration: сначала scope, затем batched fan-out по независимым направлениям, проверки после каждой фазы и corrective subagents при проблемах.

Для работы нужен активный инструмент `task`. Конкретная форма dispatch зависит от настройки `task.batch`.

### Хорошие кейсы

- Security-аудит или review по независимым осям.
- Миграция публичного API или масштабное переименование.
- Большое обновление с множеством callsites.
- Работа, где критично не пропустить подсистему, риск или проверку.

### Пример

```text
workflowz: проведи review текущего diff. Отдельно проверь безопасность,
обратную совместимость, missed callsites и тестовое покрытие. Верни только
подтверждённые находки с файл:строка и конкретным исправлением.
```

### Не нужен

Для обычной реализации в нескольких файлах без сложных зависимостей.

---

## Памятка

- **Сложно думать** → `ultrathink`
- **Много независимой работы** → `orchestrate`
- **Нужен строгий, проверяемый процесс** → `workflowz`

## Официальные исходники OMP

Установленный пакет OMP содержит первичные источники:

- `~/.bun/install/global/node_modules/@oh-my-pi/pi-coding-agent/src/modes/ultrathink.ts`
- `~/.bun/install/global/node_modules/@oh-my-pi/pi-coding-agent/src/modes/orchestrate.ts`
- `~/.bun/install/global/node_modules/@oh-my-pi/pi-coding-agent/src/modes/workflow.ts`
- `~/.bun/install/global/node_modules/@oh-my-pi/pi-coding-agent/src/prompts/system/ultrathink-notice.md`
- `~/.bun/install/global/node_modules/@oh-my-pi/pi-coding-agent/src/prompts/system/orchestrate-notice.md`
- `~/.bun/install/global/node_modules/@oh-my-pi/pi-coding-agent/src/prompts/system/workflow-notice.md`
